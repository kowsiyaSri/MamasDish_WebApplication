# Mama's Dish

Mama's Dish is a full-stack recipe-sharing web application that showcases culturally diverse recipes from around the world. The platform connects users with authentic dishes created by home cooks and professional chefs, making it easier to discover unique recipes beyond those typically found in mainstream cookbook applications.

## Features

- Browse and explore international recipes
- Search recipes using advanced filtering and recommendation features
- View nutritional information through Nutritionix API integration
- Access location-based functionality with Google Maps API
- Discover diverse cuisines from different cultures

## Project Overview

This project was developed as a Sheridan College Capstone Project with the goal of increasing access to culturally diverse recipes. The platform provides users with authentic international dishes while leveraging advanced search capabilities and nutritional insights to enhance the overall cooking experience.
